Title (max 255 characters):
AgentX: Adding a Safety Decision Layer to Tool-Calling AI Agents
Description (max 512 characters):
AgentX explores how Strands Decider 2B can review proposed tool calls before they proceed. Its reusable #guardrails pattern evaluates argument grounding, explicit user intent, missing authorization or confirmation, and unsafe operations. The prototype uses simulated in-memory tools to demonstrate Proceed, Guide, and Deny outcomes without executing real-world actions.
